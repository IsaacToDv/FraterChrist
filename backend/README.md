Estructura objetivo:

~~~text
backend/
├── manage.py
├── config/
└── apps/
~~~

El código se incorporará comenzando por la [Issue #20](https://github.com/IsaacToDv/FraterChrist/issues/20). Esta carpeta todavía no contiene una API implementada. Consulta [la arquitectura](../docs/ARQUITECTURA.md) antes de añadir módulos.
