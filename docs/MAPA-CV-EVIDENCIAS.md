## Mantener el mapa honesto
- Cambiar a **Demostrado** solo con evidencia verificable enlazada.
- Describir claramente resultados parciales.
- Una biblioteca usada no demuestra por sí sola dominio de la tecnología.
- Distinguir conocimiento previo, aprendizaje en curso y competencia demostrada.
- Mantener este mapa y el README sincronizados.
