# Progreso

Bitácora del aprendizaje y del desarrollo del MVP personal de FraterChrist. El objetivo es conservar evidencia clara de qué se trabajó, qué se aprendió, qué problemas aparecieron y cómo se verificaron las soluciones.

> **Regla de registro:** una tarea solo se marca como completada cuando el cambio existe y se puede comprobar. Las ideas, diagramas y decisiones de diseño se registran como planificación, no como funcionalidades implementadas.

## Estado inicial

El repositorio tiene el alcance del MVP, la arquitectura prevista, los requisitos y el backlog definidos. **La aplicación todavía no está implementada.**

## Registro de aprendizaje

Consulta [REGISTRO.md](REGISTRO.md) para ver las entradas por sesión y añadir nuevas observaciones.

En cada entrada intenta guardar:

- **Objetivo:** qué intentabas resolver.
- **Trabajo realizado:** archivos o comportamiento que cambió.
- **Aprendizaje:** conceptos técnicos comprendidos y decisiones tomadas.
- **Dificultad y solución:** qué falló y cómo lo investigaste.
- **Evidencia:** pruebas ejecutadas, capturas, commits o enlaces a Issues/PRs.
- **Siguiente paso:** una acción pequeña y concreta.
