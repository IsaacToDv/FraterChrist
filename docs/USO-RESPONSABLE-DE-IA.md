Las herramientas de IA pueden ayudar a investigar, comparar opciones, revisar código o documentar. La responsabilidad técnica sigue siendo del autor.

## Criterios
- No aceptar una respuesta solo porque parezca convincente.
- Verificar APIs y dependencias con documentación fiable.
- Ejecutar pruebas y revisar casos límite.
- No enviar secretos ni datos privados a herramientas externas.
- No atribuirse comprensión de código que no se pueda explicar.
- Registrar solo usos relevantes, no cada corrección menor.
