# Declaración de uso de inteligencia artificial

Se utilizó ChatGPT de OpenAI como apoyo para organizar la documentación, comparar alternativas de arquitectura y preparar el primer alcance del MVP.

La asistencia de IA no implica que la aplicación esté implementada, probada o lista para producción. Las decisiones técnicas y los cambios futuros deben revisarse y comprobarse con el código y documentación vigentes.

No se utilizaron datos reales de usuarios para elaborar los documentos. Las pruebas y ejemplos de datos del proyecto deben ser sintéticos.
