# Módulos de la aplicación

Los módulos de dominio se crearán cuando cada reto los necesite. La primera versión no requiere todas las secciones de FraterChrist.

La estructura se definirá al implementar la API; cada módulo debe mantener responsabilidades claras y exponer una interfaz comprensible. Consulta `docs/ARQUITECTURA.md` y `docs/PLAN-APRENDIZAJE.md`.
